Obsidian Mobile Sync

Конфиденциальность

Обновлено: 11 ноября 2026 года

Obsidian Mobile Sync — личная настройка плагина GSync и Google OAuth для синхронизации собственных заметок. Сайт поддерживается владельцем аккаунта ASPredein.

Google Drive и устройства

Плагин получает доступ к содержимому и метаданным файлов Google Drive, чтобы сравнивать версии и синхронизировать выбранную папку с локальным хранилищем Obsidian. Включённая передача удалений позволяет перемещать удалённые файлы в корзину.

Запрашиваемые права распространяются на весь Google Drive; ограничение выбранной папкой обеспечивает GSync. Обмен файлами происходит напрямую между устройством и API Google. Заметки и вложения не отправляются на этот сайт или на callback автора плагина.

Client secret и OAuth-токены сохраняются GSync в настройках на устройстве. Обмен кода на токены и обновление токенов выполняются плагином напрямую с Google. Эта страница их не запрашивает и не получает.

Страница возврата

Google направляет браузер на callback с одноразовым кодом и параметром state. State содержит случайное значение и закодированное имя хранилища. При отмене входа вместо кода может передаваться идентификатор ошибки.

Скрипт страницы возвращает эти параметры в установленный Obsidian через ссылку obsidian://gsync-auth. Он очищает query-параметры из текущего адреса браузера, не записывает данные в cookies или локальное хранилище, не отправляет сетевые запросы и не использует аналитику. Страница не показывает код или state в тексте.

GSync применяет PKCE: проверочное значение для обмена кода остаётся на исходном устройстве. Сам callback не обменивает код на токены.

Хостинг GitHub Pages

Сайт размещён на GitHub Pages. Первоначальный HTTPS-запрос содержит адрес callback с query-параметрами, поэтому инфраструктура GitHub получает этот запрос, IP-адрес и стандартные сведения HTTP. Очистка адресной строки не удаляет уже обработанные сервером сведения.

Владелец сайта не добавляет собственное серверное журналирование. Обработка и хранение служебных данных хостинга регулируются политикой GitHub. Для аккаунта и файлов Drive действуют правила Google.

Контроль и удаление

Доступ приложения можно отозвать в настройках подключений Google. После этого новые обращения GSync к Google потребуют повторного разрешения.

Чтобы остановить работу на устройстве, отключи GSync. Локальные настройки, включая сохранённые токены, удаляются вместе с данными плагина; файлы заметок и копии в Drive управляются отдельно. Отключение плагина само по себе не удаляет заметки из Drive.

Этот личный инструмент не использует данные Google для рекламы, продажи данных или обучения моделей. По вопросам сайта можно обратиться через репозиторий проекта, не прикладывая коды входа, секреты, токены или содержимое заметок.
